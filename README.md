# Instruções
Este é um arquivo portable, o que significa que não é necessário realizar nenhuma instalação. Basta executar e encerrar após o uso.

## Como iniciá-lo automaticamente em segundo plano ao iniciar o Windows
Basta copiar o arquivo `LEVI Hand e Zoom.exe` para o diretório `C:\Users\usuario\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`
